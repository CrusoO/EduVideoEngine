# ADR 0113: Engine V2 wave 6 (Maths B: statistics, probability, calculus, sequences, matrices, complex numbers, conics, linear programming, diagrams) and the minus sign in a label

Status: Proposed, 2026-11-12. The owner accepts it. Builds on ADR 0100, 0107, 0108, 0110, 0111 and 0112. Touches no frozen file and no item of section 15 of the architecture. `docs/ENGINE_INTERFACE.md` is unchanged.

## Decision (first part, committed first): a leading minus sign in a label
The closed label alphabet of an object (`SAFE_LABEL` in `packages/pipeline/objects/spec.ts`, wave 0) began with "a letter or a digit", so a label could not start with a minus sign: the label of a negative number on a number line or an axis had to be written `x=-2`. Wave 5 worked round it and listed it as a limit (ADR 0112, "Limits of what is drawn").
1. A label may now start with a minus sign, the hyphen-minus or the Unicode minus (U+2212), **only when a digit follows it at once** (`-2`, `-3.5`, `−7.25`). A minus before a letter, two signs, a lone sign and a sign followed by a space are still refused. The Unicode minus is also allowed inside a label (`x=−2`). The total stays 1 to 60 characters, the sign counted.
2. Nothing the old alphabet allowed is refused, and nothing it refused for another reason is let in: a seeded property test compares the old and the new pattern on 4000 random strings that do not start with a minus. A label is still refused if it holds personal data, a secret or a banned positioning phrase.
3. The story sanitiser keeps such a text unchanged (its list-marker rule needs a space after the dash, which the alphabet does not allow after a leading minus), and a test shows a drawn text `−2` reaches the page. With `ENGINE_OBJECTS_V2` off the page bytes are identical (test Q1 in `objects-label-minus.test.ts`): the alphabet is read only when an object request is parsed or a drawing is laid out.
4. The older drawers are untouched: their tick labels keep the form they have (`x=-2`), and the older tests that hold a pattern of their own for the old alphabet still pass because the new pattern accepts everything the old one did. The wave-6 drawers use the leading minus for the tick labels of an axis.
