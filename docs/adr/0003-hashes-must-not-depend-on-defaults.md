# ADR 0003: no parse-time defaults in the bundle schema

Status: accepted. Found by a test in step (a).

zod `.default()` filled `gap: "normal"` on parse, so a parsed bundle hashed differently from the sealed one and the
validator rejected a correct fixture. Rule: a field is either required or optional-without-default; the consumer
applies its own default at use. The test "hashes do not depend on parse-time defaults" guards it.
A scene hash covers the scene, the sentences of its beat and the expression trees it references, so an edit reopens
exactly the affected scene (cache, review, analytics share one identity).
